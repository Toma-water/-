# 小説生成パイプライン — Codexでの進め方

「出来事を書く → 心情の推定 → 表現の設計 → 本文化」を自動化するためのプロンプト集と資料置き場。

## 全体の流れ

```
出来事(自分で書く)
  → ① ストーリーバイブル/キャラシート作成(最初に1回だけ)
  → ② 内面分析(シーンごと・JSON出力)
  → ③ 表現設計(シーンごと・JSON出力)
  → ④ 本文生成
  → ⑤ 推敲チェック
```

## フェーズ1: まずは手動で回す(ここから始める)

自動化の前に、プロンプトの精度を上げる期間。Codexのチャットに以下の順で送る。

1. `prompts/01_story_bible.md` の中身 + `events/scenes.md` の中身を貼って送る
   → ストーリーバイブルとキャラシートができる。【要確認】の質問に答えて確定させ、
   `story_bible.md` / `characters.md` として保存する
2. シーン1について `prompts/02_inner_analysis.md` を送る → 出てきたJSONを読み、
   「ここは違う」を指摘して修正 → 確定したら保存
3. `prompts/03_expression_plan.md` を送る → 同様に修正・確定
4. `prompts/04_prose.md` を送る → 本文が出る
5. `prompts/05_review.md` でチェック → 気になる指摘だけ反映

これをシーン2〜3まで繰り返し、「毎回同じ修正をしているな」と気づいたら
その修正内容をプロンプト本文に書き足す。**ここがパイプラインの品質の8割を決める。**

## フェーズ2: 自動化する

プロンプトが安定したら、Codexに `prompts/06_build_automation.md` を送って
スクリプト(CLIツール)を作らせる。以後は:

```
events/scene_N.md に出来事を書く → コマンド1発 → output/scene_N/ に本文まで生成
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `events/scenes.md` | 出来事集(シーン1〜7の整理版) |
| `prompts/01_story_bible.md` | 設定資料を作らせるプロンプト(最初に1回) |
| `prompts/02_inner_analysis.md` | 内面分析(シーンごと) |
| `prompts/03_expression_plan.md` | 表現設計(シーンごと) |
| `prompts/04_prose.md` | 本文生成 |
| `prompts/05_review.md` | 推敲チェック |
| `prompts/06_build_automation.md` | Codexに自動化スクリプトを作らせる依頼文 |

## コツ

- **②の内面分析は必ず自分で確認・修正してから③へ進む。** ここが作品の芯になる。
- 修正の指摘は「感情が違う」だけでなく「悔しさではなく諦め」のように置き換え先を言う。
- 本文の文体を寄せたいときは、`prompts/04_prose.md` の「文体見本」に
  自分が過去に書いた文章を貼る。
