# プロンプト② 内面分析(シーンごとに送る)

`(シーンN)` の部分を対象シーンに置き換えて送る。
※出てきたJSONは必ず自分で読み、違う部分を指摘して修正してから③へ進むこと。

---

あなたは小説の心理描写の専門家です。
以下の資料を踏まえて、【シーンN】における登場人物の内面を分析してください。

## 資料

### ストーリーバイブル
(story_bible.md の中身を貼る)

### キャラクターシート
(characters.md の中身を貼る)

### これまでのあらすじ
(前のシーンまでの要約を貼る。シーン1なら「物語の冒頭」と書く)

### 今回の出来事
(events/scenes.md から該当シーンを貼る)

## 出力形式

次のJSON形式だけで出力してください。説明文は不要です。

```json
{
  "scene": 0,
  "pov_character": "視点人物",
  "characters": [
    {
      "name": "人物名",
      "surface_emotion": "表に出している感情・態度",
      "hidden_emotion": "内に秘めた本当の感情",
      "internal_conflict": "葛藤(なければnull)",
      "motivation": "このシーンでの言動の動機",
      "body_language": "感情が漏れ出る身体的なサイン(表情・仕草)の案"
    }
  ],
  "what_to_convey": "このシーンで読者に伝えたいこと(1〜2文)",
  "emotional_arc": "シーン内の感情の流れ(開始 → 転換点 → 終了)",
  "reader_feeling": "シーンの終わりで読者に残したい感情",
  "foreshadowing": ["このシーンで張る/回収する伏線"]
}
```

## 分析のルール

- キャラクターシートと矛盾する内面を作らないこと。
- 視点人物以外の内面は「視点人物から観察できる範囲のサイン」として
  body_language に反映すること(地の文で直接書けないため)。
- 主人公の少女については、「かわいそうな子」として安易に描かず、
  本人は自分を不幸と思っていない、という軸を守ること。

出力後、私が意図と違う部分を指摘するので、対話しながら修正してください。
