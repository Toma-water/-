# ノーズコーン合わせ目 シールリップバンド

GFRP製ノーズコーン半割どうしの合わせ目がガタつき、隙間から空気が入る問題への対策部品。
黄色ライン（型のパーティング面 Z=55.3mm の縁ライン）の実測データに沿って、
**縦に立ち上がるU字の壁（リップバンド）** を生成する。

- 下半分（接着ゾーン 8mm）: 固定側シェルの内面に接着＋くぎ/リベットで固定
- 上半分（リップ 8mm）: 合わせ面から突き出し、閉じたときに相手側シェルの内側に入る
- 合わせ面の位置に **段差 0.4mm**（工具箱ステップ方式）があり、相手シェルとの
  クリアランスになる。差し込み式なので開放時はそのまま真っ直ぐ離れる（即時解放OK）

## ファイル

| ファイル | 内容 |
|---|---|
| `generate_seal_lip.py` | STL生成スクリプト（パラメータはファイル冒頭で調整） |
| `make_preview.py` | プレビュー図の描画 |
| `nosecone_yellow_edge_samples.csv` | Fusion 360 から書き出した黄色ラインの実測点列 |
| `output/nosecone_seal_lip_band.stl` | 本体。90.2 × 214.8 × 16.0 mm（縦=Y軸がノーズコーン軸） |
| `output/nosecone_seal_lip_test_coupon.stl` | 嵌合テスト用 40mm 直線クーポン（先にこれで確認） |
| `output/preview.png` | 3面プレビュー |

## 寸法パラメータ（デフォルト）

| パラメータ | 値 | 意味 |
|---|---|---|
| `GLUE_GAP` | 0.2 mm | 黄色ライン→接着ゾーン外面のオフセット（接着剤層） |
| `STEP` | 0.4 mm | 段差＝リップ外面の追加オフセット（相手シェルとのクリアランス） |
| `THICKNESS` | 2.4 mm | 接着ゾーン肉厚（リップ肉厚は 2.4 − 0.4 = 2.0） |
| `GLUE_H` | 8.0 mm | 接着ゾーン高さ |
| `LIP_H` | 8.0 mm | リップ突き出し量 |

## 前提（重要）

- 黄色ライン＝**シェル内面**の輪郭とみなしている（オス型に積層 → 部品内面が型面になるため）。
  もし型がメス型（部品外面が型面）なら、`GLUE_GAP` にGFRP板厚を足して再生成すること。
- 手積みGFRPの板厚・トリムのばらつきがあるため、**まずテストクーポンを印刷して**
  実機シェルの直線部（後端側の直線区間）に当てて嵌合を確認し、
  きつい/緩い場合は `GLUE_GAP` / `STEP` を 0.1mm 刻みで調整して再生成する。

## 印刷のめやす

- 置き方: そのまま（Z=0 が底）。立ち壁16mmなのでブリム推奨
- フットプリント 90×215mm → 220×220ベッドに収まる（足りなければ45°回転）
- ノズル0.4mm / 壁3周以上 or 100%infill、PETG推奨（衝撃と接着性のバランス）
- 接着は エポキシ or PETG対応の構造用接着剤＋くぎ/リベット（φ2程度、現物合わせで穴あけ）

## 再生成

```bash
python3 generate_seal_lip.py   # STL生成
python3 make_preview.py        # プレビュー図
```

# v2: スナップ嵌合バンド(受け/攻め) + 磁石バンド

`generate_snap_and_magnet.py` で生成。プレビューは `output/preview_snap_magnet.png`。

## A. スナップ嵌合バンド(2ファイル・工具箱方式)

閉じると「カチッ」とはまり、ちょっとやそっとでは離れないラッチ機構。

| ファイル | 取付先 | 内容 |
|---|---|---|
| `output/nosecone_snap_band_female.stl` | シェルA(受け) | 内面に全周の溝を持つバンド。深さ8mm |
| `output/nosecone_snap_band_male.stl` | シェルB(攻め) | 接着ゾーン8mm+舌7.5mm。舌の外面にビード(爪) |
| `output/nosecone_snap_coupon_female.stl` | テスト用 | 40mm直線の嵌合テストペア。**必ず先にこれで** |
| `output/nosecone_snap_coupon_male.stl` | テスト用 | カチッと感・保持力・開放力を確認する |

- ビードは全周ではなく **30mm×4区間(直線部2+曲線部2, 計120mm)**。
  保持力が強すぎ/弱すぎの場合は `BEAD_SEGS` / `BEAD_LEN` / `BEAD`(張り出し0.3) を調整。
  受けの溝は全周にあるので、攻め側だけ作り直せばよい。
- 攻めの段差(ledge)が受けの上面に着座する → ここがエアシール面。
  1〜2mm厚のスポンジテープ(EPDM)を挟むと気密が大きく向上する。
- 開放はまっすぐ引き離せば外れる(保持フランク55°)。パラシュート放出力で開く想定。
- 材質は **PETG推奨**(スナップの繰り返したわみにPLAは割れやすい)。
- 印刷向き: 生成済みSTLはそのまま印刷可(受け=溝側が上/攻め=舌先が上)。ブリム推奨。
- 接着ゾーン外面にドラフト0.8mm付き(シェル曲面の逃げ)。先端付近はシェルの
  曲率がきついので、現物合わせでヤスリ調整 or エポキシパテ充填。

## B. 磁石バンド v3 (最新・新外形・CAD+STL)

**2026-07-09作り直し。** ユーザー提供の新しいノーズコーン外形スケッチに準拠:
リム外形 = **曲線(1/4楕円)のみ、高さ135.60 × 半幅45.60mm、直線スカート無し**。
旧215mm外形ベースの磁石バンド(`nosecone_magnet_band.stl` / `generate_magnet_band.py`)は削除した。

生成は `generate_magnet_band_v3.py`(cadquery使用)、プレビューは `output/preview_magnet_band.png`。

| ファイル | 内容 |
|---|---|
| `output/nosecone_magnet_band_v3.step` | **CADファイル**(Fusion 360にそのままインポート可) |
| `output/nosecone_magnet_band_v3.stl` | 印刷用STL。90.8 × 135.4 × 8mm |

- **片側の半割にだけ**取り付ける。段差(リップ)無し = 合わせ面(z=8)はフラット。
- **固定はM3ネジ**: Φ3.4の貫通穴を6か所(弧長の4.5/20/40/60/80/95.5%位置、高さz=4)。
  シェル側は現物合わせでΦ3.2〜3.4を開け、M3ネジ+ナット(または鬼目)で共締め。
- 磁石座(内向き突起、幅13.2×奥行13.2)5か所(弧長の10/30/50/70/90%位置。50%=先端)。
  上面は合わせ面-3mm → 厚さ3mmの磁石(例: ネオジム φ10×3)でツライチ。
  位置決め縁(高さ1.5mm、窓10.8mm角)付き。
- **相手側の半割**には、対応する位置に磁石(逆極性)か鉄ワッシャーを直接接着する。
- 気密が必要ならフラットなリム面(z=8)に薄いスポンジテープ(EPDM)を貼る。
- 印刷: そのまま(z=0が底)。サポート不要。PETG/PLAどちらでも可(スナップと違い たわみ無し)。

### パラメータ調整(`generate_magnet_band_v3.py` 冒頭)

| パラメータ | 値 | 意味 |
|---|---|---|
| `A_LEN` / `B_RAD` | 135.60 / 45.60 | 外形の高さ / 半幅(スケッチの寸法) |
| `HOLE_D` / `HOLE_FRACS` | 3.4 / 6か所 | ネジ穴径 / 位置(弧長分率) |
| `MAG_T` / `MAG_POCKET` | 3.0 / 10.8 | 磁石厚 / 磁石窓 |
| `BOSS_FRACS` | 5か所 | 磁石座の位置(弧長分率) |

