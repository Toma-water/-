# 改稿版（原文の情報のみ）

　息を吸うたび、喉の奥が灼ける。

　それでも、私は走っていた。

　首筋に彫られた未完成の紋が、脈を打つたびに痛む。走るほどに脈は速くなり、痛みも速くなる。

　ドンっ。

　誰かに身体が当たった。よろけて、それでも足は止めない。今はそんなこと、どうでもいい。

　ただ、白いコート越しに、目があった気がした。男は少し目を見開いて、驚いたような顔をしていた。

「ちょっと……」

　後ろから声が聞こえる。振り返っている余裕などない。

　そして、その後ろからは、ぞろぞろと近づいてくる音が聞こえていた。

　角を曲がる。曲がって、そして——その先は、行き止まりだった。

　髪をつかまれ、後ろへ引き倒される。手足を押さえ込まれ、そのまま拘束される。指の一本も動かせない。

　前を見ると、いかにも成金そうな男が、こちらを見ていた。

「よくも逃げてくれたな。お前が商品ではなかったら、殺しているところだ」

　そう言って、ゆがんだ笑顔をこちらに見せつけてくる。

　首筋の紋が、応えるようにいっそう熱を持った。

　もう、ここからは逃げられない。

　また、あの暗い牢獄に戻らないといけない。そして今度こそ、この紋は完成させられる。

　そんなのは耐えられなかった。

　だから、手段を選んでいるわけにはいかなかった。

「私を食べていい。だから、助けて」

　私がそう言うと、身体が燃え上がった。

　その熱さで、拘束されていた手足が自由になる。押さえつけていた男たちが、悲鳴をあげて離れていく。

　全身に、チクリという痛みが絶え間なく押し寄せる。

「お、お前、どういうつもりだ」

　成金の男が、一歩下がった。

「——もういい。お前の命なんてどうでもいい。殺せ」

　顔を真っ赤にして、こちらをにらんでいる。

　私は小さく、ふっと笑った。

　最初からそう言ってくれれば、こっちも遠慮しなくてよかったのに。

　身体に着いた炎を操作する。動かした分だけ、体の痛みがより一層ひどくなる。

　男たちが、水の刃をこちらに向けて放ってくる。

　私は炎を一粒だけ放った。

　水の刃と炎は衝突し、消滅する。

　男たちはあからさまに動揺したようだった。

　私は炎を男たちに向け、放とうとする。

　その時、そよ風を頬に感じたと思ったら、私の周りを風が包んでいた。

　私の炎が、かき消されていく。指先に集めた熱が、あっけなく持っていかれる。

　白いコートを羽織った男が、いつの間にか、私のすぐそばに立っていた。

「皆さん、こんなところで魔法を使っては危ないですよ」

　この状況で出す声じゃなかった。まるで、道端の喧嘩でも止めにきたような口ぶりだった。

　成金の男は、彼を見て、大げさに息を吐いた。

「いや、ありがとう。君が居なかったら今頃我々は、あいつに殺されていたんだからな」

　そう言って、私を指さした。

「へえ〜」

　男は軽く相槌を打って、それから首を傾げた。

「そういえば、彼女はさっき追われていたように見えたんですが、何をしたんです？」

「ああ、あいつは奴隷として売り出される予定だったんだが、奴隷紋をつけられる直前に、逃げ出してしまってな。それで、追っていたというわけだ」

　彼が、私の首筋を見る。

　確かにそこには、まだ完成していない奴隷紋がある。

「じゃあ、あの人は奴隷なんですね」

「ああ、そうだ。灰色の髪が珍しいってんでいい商品になるかと思っていたんだが、なかなかに手がかかる。店に戻ったら、二度と逆らえないように、徹底的に調教してやる」

　男は鼻息荒く言った。

　彼らの話す声が、だんだんと遠くなっていく。頭もぼーっとする。

　身体が少し倒れる。

「おっと」

　男が私の身体を支える。

　コートは、ひんやりしていて、気分がよかった。熱を持ったままの頬に、それがちょうどよかった。

「ああ、そうだ。商人さん」

　頭のすぐ上から、声が降ってくる。

「彼女を、買うことはできますか？」

「……金さえ払ってくれりゃあ。ただ、奴隷紋を完成させる必要がある」

「大丈夫ですよ。逃げられた時は、その時はその時だと思うことにします」

　衣擦れの音がして、それから、硬貨の音が聞こえてくる。

　彼は本当に払ったらしい。

　まぶたが重い。この人が何を考えているのか、私にはさっぱりわからなかった。助けられたのか、買われたのか。それすらもう、どっちでもいい気がした。

「眠っていていいよ」

　敬語が、外れていた。

　その声に安心したのだろうか——私は、ひんやりとしたコートの上で、眠った。
