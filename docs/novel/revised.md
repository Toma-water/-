# 灰の商品（第一話・改稿版）

　息を吸うたび、喉の奥が灼ける。

　それでも足は止められなかった。

　石畳を蹴る。裸足の裏が拾った冷たさは、走るそばから熱に変わっていく。首筋——彫りかけの紋が、心臓と同じ拍で脈を打つ。打つたびに、焼けた針を押し込まれたような痛みが背骨まで走った。

　まだ完成していない。だからまだ、私は私だ。

　夕暮れの市場は人でごった返している。香辛料と魚と、汗の匂い。値切る声。荷車の軋み。その隙間へ身体をねじ込むように走る。汗で額に貼りついた灰色の髪が、視界の端で揺れた。

　ドンッ。

　誰かの肩とぶつかった。よろける。それでも足は止めない。今はそんなこと、どうでもいい。

　ただ、視界の隅を白が掠めた。

　白いコート。その襟の上から、目が合った——気がした。男は少しだけ目を見開いていた。驚いた、というより、道端で拾い物でも見つけたような顔で。

「ちょっと……」

　背中に声がかかる。振り返る余裕なんてない。

　後ろから、ぞろぞろと足音が近づいてくる。革靴。三人か、四人。市場の喧騒がふつりと割れて、道があく。誰も助けない。関わらないほうが得だと、みんな知っている。

　角を折れる。折れて、そして——

　行き止まりだった。

　高い石壁。積み上がった木箱。手をかけようとした瞬間、髪をつかまれ、後ろへ引き倒された。

　石畳に頬を打ちつける。腕をひねり上げられ、膝で背中を押さえ込まれる。指一本、動かせない。

　顔を上げると、男が立っていた。指という指に指輪をはめた、いかにも成金といった風体の男。息を切らしながら、それでも笑っている。

「よくも逃げてくれたな」

　しゃがみ込み、私の顎を掴んで無理やり上を向かせる。

「お前が商品でなかったら、今ごろ殺しているところだ」

　歪んだ笑顔が、すぐ目の前にあった。首筋の紋が、応えるようにいっそう熱を持つ。

　もう、ここからは逃げられない。

　またあの暗い牢獄に戻る。鉄格子。饐えた藁。両隣から絶えず聞こえる、誰のものともつかない泣き声。そして今度こそ、紋を完成させられる。そうなればもう——「逃げたい」と思うことすら、できなくなる。

　そんなのは、耐えられなかった。

　だから、手段を選んでいる場合ではなかった。

　私は目を閉じて、胸の奥、ずっと蓋をしてきた場所へ呼びかける。

　そこに何がいるのか、私は知らない。物心ついた頃からずっと、飢えた獣のような気配だけが、そこにあった。

「——私を食べていい」

　男の手が止まる。

「だから、助けて」

　答えは、言葉ではなかった。

　身体の内側が、一度に燃え上がる。

　押さえつけていた男たちが悲鳴をあげて飛び退く。ひねり上げられていた腕が自由になる。私は咳き込みながら立ち上がった。

　全身を、チクリ、チクリと針が刺す。絶え間なく、内側から。

　これが代金だ。安いはずがない。

「お、お前、どういうつもりだ」

　成金の男が後ずさる。顔を真っ赤にして、それでも目だけが泳いでいた。

「——もういい。お前の命なんてどうでもいい。殺せ！」

　私は小さく、ふっと笑った。

　最初からそう言ってくれれば、こちらも遠慮しなくて済んだのに。

　身体にまとわりついた炎に、指先で命じる。従わせた分だけ、痛みが深くなる。チクリ、が、骨の内側を軋ませる鈍い痛みに変わっていく。

　手下たちが一斉に印を結んだ。掌の前で空気が濡れ、細く長い水の刃が三条、こちらへ放たれる。

　私は避けなかった。

　指先から、炎を一粒だけ弾く。

　水の刃と、火の粒。ぶつかった瞬間、両方が音もなく消えた。あとには白い蒸気だけが残り、路地をゆっくりと満たしていく。

　手下たちが、あからさまに動揺した。

「な——三つとも、一粒で……？」

　同じ量なら、同じだけ消える。それだけのことだ。彼らはたぶん、水は炎に勝つと教わってきたのだろう。

　蒸気の向こうで、成金の男が壁際まで下がっているのが見えた。

　私は掌を開く。集めた炎が、そこで白く縮んでいく。

　——放とうとした、その時だった。

　そよ風を感じた、と思った次の瞬間には、私の周りを風が包んでいた。

　掌の炎が、蝋燭を吹き消すようにかき消える。指先の熱が、あっけなく持っていかれた。

　白いコートを羽織った男が、いつの間にか、私のすぐ横に立っている。

「皆さん、こんなところで魔法を使っては危ないですよ」

　まるで、往来で喧嘩を止める町の役人のような口ぶりだった。この状況で、その声の温度はおかしい。

　成金の男は彼を見るなり、大げさに息を吐いた。

「いや、ありがとう。君が居なかったら今頃我々は、あいつに殺されていたんだからな」

　そう言って、私を指さす。

「へえ〜」

　男は緩く相槌を打ち、それから首を傾げた。

「そういえば彼女、さっき追われていたように見えたんですが。何をしたんです？」

「ああ、あいつは奴隷として売り出される予定だったんだが、奴隷紋をつけられる直前に逃げ出してしまってな。それで追っていたというわけだ」

　白いコートの男が、私の首筋を見る。

　確かにそこには、まだ完成していない紋がある。

「じゃあ、あの人は奴隷なんですね」

「ああ、そうだ。灰色の髪が珍しいってんで、いい商品になるかと思っていたんだが——なかなかに手がかかる。店に戻ったら、二度と逆らえないように、徹底的に調教してやる」

　男は鼻息荒く言った。

　彼らの話す声が、だんだん遠くなっていく。頭もぼうっとする。

　視界の端が、黒く欠けはじめていた。

　ああ、そうか。代金は、もう払い終わっているのか。

　膝から力が抜けて、身体が傾く。

「おっと」

　白いコートが、私の身体を支えた。

　布はひんやりとしていて、熱を持った頬に気持ちがよかった。

「ああ、そうだ。商人さん」

　頭のすぐ上で、その声がした。

「彼女を、買うことはできますか？」

　成金の男が、間の抜けた声を出した。

「……金さえ払ってくれりゃあな。ただし、奴隷紋を完成させる必要があるぞ」

「わかりました」

　衣擦れの音。それから、重たいものが石畳に落ちる音。

　彼は本当に払ったらしい。革袋の口から、硬貨の擦れ合う音が聞こえてくる。値も聞かないまま。

「……お、おい。数えていないぞ」

「足りていますか？」

「あ、ああ。足りている。足りているが……」

「よかった」

　商人の声のほうが、よほど動揺していた。

「言っておくが、こいつは逃げるぞ。紋を入れる前に一度やられている」

「大丈夫ですよ」

　男は少しも困っていない声で言った。

「逃げられた時は、その時はその時だと思うことにします」

　まぶたが重い。指の一本も動かない。

　この人が何を考えているのか、私にはまるでわからなかった。助けられたのか、買われたのか。それすらもう、どちらでもいい気がした。

　頭の上で、声が降ってくる。

「眠っていていいよ」

　敬語が、外れていた。

　その声に安心したのだろうか——私は、ひんやりとしたコートの上で、眠った。
