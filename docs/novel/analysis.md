# 原稿分析メモ（第1話 冒頭シーン）

対象：Google ドキュメント「奴隷紋／白いコートの男」冒頭稿

## 1. 良いところ（触らない・むしろ伸ばす）

- **導入の掴みが強い。** 説明ゼロでいきなり全力疾走から始まり、読者を状況の中に放り込んでいる。ライトノベルの冒頭として正しい。
- **「私を食べていい。だから、助けて。」** この一行が原稿の心臓部。何と契約しているのか、何を差し出したのかを説明しないまま撃つことで、強烈な引きになっている。**ここは絶対に説明しない**のが正解。
- **白いコートの男の飄々とした敬語。** 「皆さん、こんなところで魔法を使っては危ないですよ。」という、状況にそぐわないほど呑気な口調が、そのまま得体の知れなさになっている。
- **ラストの「眠っていていいよ」で敬語が外れる。** ここだけ素の顔が出る。作者が意識的にやったかは不明だが、この一稿でいちばん効いている技。改稿では意図的に際立たせた。
- **戦闘の勝ち方。** 主人公が力で圧倒するのではなく、炎を「一粒」で相殺するという省エネな描き方。強さの質が伝わる。

## 2. 直すべきところ

### A. 誤字・変換ミス

| 原文 | 修正 |
|---|---|
| また、あのくらい牢獄に戻らないといけない | あの**暗い**牢獄 |
| 顔を真っ赤にいてこちらをにらんでいる | 顔を真っ赤に**して** |
| 効果の音が、聞こえてくる | **硬貨**の音 |
| 「ちょっと・・・」 | 三点リーダは「……」（2つ重ね）で統一 |

### B. 時系列の崩れ（最重要）

原文では

> 「彼女を、買うことはできますか？」
> **彼は本当に払ったらしい。効果の音が、聞こえてくる。**
> 「金さえ払ってくれりゃあ。ただ、奴隷紋を完成させる必要がある。」

の順になっており、**商人が値段の話をする前に支払いが終わっている**。読者が一瞬つまずく。

→ 改稿では「買えますか」→ 商人が条件を提示 →（間を置かず）革袋を投げる → 硬貨の音 → 商人が絶句、という順に組み直した。「即金で、条件も聞かずに払う」ほうが白コートの男の異常さも出る。

### C. 「感じる／気がする」への依存

- 「痛みを感じる」「熱くなったと感じる」「ひどくなると感じた」「そよ風を感じた」「目があった気がした」

一人称なので、**感じているのは当たり前**。「感じる」を抜いて現象そのものを書くと、密度が一段上がる。

- ✗ 首筋の紋から、痛みを感じる
- ○ 首筋の紋が、脈打つたびに焼けた針を差し込む

### D. 視点と時制の混在

「私は、走っていた」（過去）と「痛みを感じる」（現在）が同じ段落に同居している。
→ **逃走・戦闘は現在形、回想と説明は過去形**、という原則で統一した。緊迫パートが現在形だと臨場感が出て、意図的な使い分けとして読める。

### E. 白コートの男の再登場が偶然すぎる

冒頭でぶつかった男が、たまたま行き止まりに現れる。このままだと「ご都合」に見える。
→ **一言だけ**、彼が興味を持って追ってきたと分かる台詞を足した（「あんまり急いでいらしたので、つい気になって」）。伏線ではなく、**彼が最初から主人公を"見ていた"**という不穏さに変換している。

### F. 主人公の「灰色の髪」の出し方

原文では終盤、商人の台詞で初めて出てくる。読者は最後まで主人公の姿を知らないまま読むことになる。
→ 冒頭の走行中に一度だけ視界に入れておき、商人の台詞で「なぜそれが価値になるのか」を回収する二段構えにした。

### G. 描写の密度が均一

原稿は全編ほぼ同じ密度で書かれているため、山場が山場に見えない。
→ **逃走＝短文の連打／捕縛＝一拍止める／契約＝改行を割って落とす／戦闘＝畳みかけ／交渉＝会話中心で静かに**、と段落のリズムを変えた。

### H. 「代償」が痛みの一種類しかない

「チクリという痛み」だけで最後まで通しているため、契約の恐ろしさが伝わりきらない。
→ **チクリ → 骨の内側が軋む → 視界の端が黒く欠ける**と段階的に悪化させ、「このまま使えば死ぬ」ことを読者に体感させた。だから彼女が眠り込むラストが必然になる。

## 3. 世界観について（説明しないための整理）

本文では説明しないが、書き手として決めておくと筆が迷わない項目：

- **奴隷紋**：完成させると本人の意思を縛る。未完成＝まだ効かない。だから彼女は「今しか逃げられない」。この緊急性が第1話の推進力。
- **魔法の属性**：商人の手下＝水、主人公＝炎、白コート＝風。第1話で三属性を見せておくと、以後の説明が要らない。
- **炎の出所**：主人公の中にいる「何か」。名前も正体も第1話では伏せる。代償は身体そのもの。
- **白コートの男**：主人公が炎を使えることを見た上で、値段も聞かずに買った。**善意で助けたのか、価値を見抜いて確保したのか分からない**——この曖昧さを最後まで崩さないのが、この話の面白さ。
