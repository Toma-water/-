# 分析メモ（原文の情報のみで改稿）

## 方針

原稿に無い設定・小道具・台詞は一切足していない。加筆は「すでに書かれている要素を掘り下げる」ことに限定した。

## 1. 誤字・変換ミス

| 原文 | 修正 |
|---|---|
| また、あのくらい牢獄に戻らないといけない | あの**暗い**牢獄 |
| 顔を真っ赤にいてこちらをにらんでいる | 顔を真っ赤に**して** |
| 効果の音が、聞こえてくる | **硬貨**の音 |
| 「ちょっと・・・」 | 三点リーダは「……」で統一 |
| その熱さか、拘束されていた手足が自由になる | その熱さ**で** |

## 2. 時系列の崩れ（最重要）

原文の順番：

1. 「彼女を、買うことはできますか？」
2. **彼は本当に払ったらしい。効果の音が、聞こえてくる。**
3. 「金さえ払ってくれりゃあ。ただ、奴隷紋を完成させる必要がある。」
4. 「大丈夫ですよ。逃げられた時は、その時はその時だと思うことにします。」

**商人が値段の話をする前に、支払いが終わっている。** 台詞の順番はそのままに、支払いの一文だけを4の後ろへ移動した。

これで「買えますか → 条件提示 → 大丈夫ですよ → 支払い」となり、「大丈夫ですよ」が「奴隷紋を完成させる必要がある」への返答として正しくつながる。彼が**紋を完成させるつもりがない**ことも、この順番なら読み取れる。

## 3. 「感じる／気がする」の重複

原文には7回出てくる。一人称なので、感じているのは当たり前。抜いて現象そのものを書いた。

- ✗ 首筋に彫られた未完成の紋から、痛みを感じる
- ○ 首筋に彫られた未完成の紋が、脈を打つたびに痛む

- ✗ 首筋の紋が、より一層熱くなったと感じる
- ○ 首筋の紋が、応えるようにいっそう熱を持った

- ✗ 体の痛みが、より一層ひどくなると感じた
- ○ 動かした分だけ、体の痛みがより一層ひどくなる

「目があった気がした」と「そよ風を感じた」は、**確信していないことが意味を持つ場面**なので残した。

## 4. 時制の混在

「私は、走っていた」（過去）と「痛みを感じる」（現在）が同じ段落に同居している。

→ 逃走・戦闘は現在形、回想と説明は過去形で統一した。緊迫パートが現在形だと、意図的な使い分けとして読める。

## 5. 「回避する」の語が合っていない

> 私はそれを、炎を一粒放ち、回避する。
> 水の刃と炎は衝突し、消滅する。

避けたのではなく、**撃ち落として相殺している**。次の一文と食い違うので「私は炎を一粒だけ放った」に整理した（避けなかったことは前後で伝わる）。

## 6. 段落のリズムが均一

全編ほぼ同じ密度で書かれているため、山場が山場に見えない。

改行位置だけを調整して、
- 逃走＝短文を続ける
- 行き止まり＝一行で落とす
- 契約＝前後に空白を作る
- 交渉＝台詞主体で静かに

とリズムを変えた。文字数はほとんど増やしていない。

## 7. 加筆したところ（すべて既出要素の掘り下げ）

| 箇所 | 加筆の中身 | 根拠となる原文 |
|---|---|---|
| 冒頭 | 走るほど脈が速くなり、痛みも速くなる | 「走っていた」「紋から痛みを感じる」 |
| 拘束 | 指の一本も動かせない | 「手足を拘束される」 |
| 牢獄 | 今度こそ紋は完成させられる | 「奴隷紋をつけられる直前に逃げ出した」 |
| 発火 | 男たちが悲鳴をあげて離れる | 「その熱さで手足が自由になる」 |
| 笑う | 最初からそう言ってくれていれば | 「私は小さくふっと笑う」 |
| 風 | 指先に集めた熱が持っていかれる | 「私の炎がかき消されていく」 |
| 一言目 | この状況で出す声ではなかった | 「こんなところで魔法を使っては危ないですよ」 |
| コート | 熱を持ったままの頬によく効いた | 「ひんやりしていて、気分がよかった」 |
| 終盤 | 助けられたのか、買われたのか | 「その声に安心したのだろうか」 |
| 最終行 | 敬語が、外れていた | 「眠っていていいよ」 |

## 8. 原稿でいちばん効いている一行

**「眠っていていいよ」**

ここまで彼は全編敬語で通している。最後の一行だけ敬語が外れる。

作者が意識的にやったかどうかはわからないが、この一稿でいちばん上手い箇所なので、直前に一行だけ足して見落とされないようにした。**説明はしていない。**
