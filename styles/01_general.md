# 執筆ルール 01〔一般〕— なろう・カクヨム標準の軽い文体

このファイル1枚で完結する。小説本文を書くときは、ここに書いてあることを**全部**守る。
「うまく書こう」としない。規則どおりの文章のほうが、うまい文章より読まれる。
守れているかは感覚で判断しない。§11のチェック手順で機械的に確認する。

## 0. このスタイルの狙い

スマホで指を止めずに読める、会話中心の軽い文体。
読者は主人公の目線と内心に乗って話を追う。地の文は最小限の交通整理に徹する。

## 1. 出力の絶対ルール

- 本文だけを出力する。「以下が本文です」などの前置き・後書き・解説は書かない
- 指定された文字数・話数に従う。指定がなければ1話2,500〜3,500字
- 本文中で設定を解説しない。設定は行動と結果で小出しにする

## 2. 視点と人称

- 一人称（俺／私）。作品開始時に決めた人称は絶対に変えない
- 視点人物が知らないこと・見えないものは書かない。他人の内心を地の文で断定しない（「〜ようだった」「〜らしい」で受ける）
- シーンの途中で視点を切り替えない。転換は空行＋「◇◇◇」＋空行
- 内心のツッコミ（「いや、無理だろ」など）は地の文にそのまま書いてよい。**15行に2回まで**
- 地の文は常体（「〜た」「〜る」中心）。「〜である」は使わない

## 3. 文型 — 地の文で書いていい文は4種類だけ

| 型 | 内容 | 例 |
|---|---|---|
| A 動作文 | 誰かが何かをする | 俺は剣を抜いた。 |
| B 知覚文 | 視点人物が見た・聞いた・感じた事実 | 土の匂いがした。 |
| C 思考文 | 視点人物の判断・内心 | まずい。囲まれた。 |
| D 状態文 | 場や物の説明 | 壁は崩れかけていた。 |

- **D状態文は1シーン（◇〜◇の間）に3回まで。**雰囲気だけの文（「夜は静かだった」「空気が重い」）はDに数える
- 段落は原則AかBで始める。Dで始めてよいのはシーン転換直後の1回だけ

## 4. 表記ルール（機械的に守る）

| 項目 | ルール | 例 |
|---|---|---|
| 三点リーダー | 「……」を2個1組で使う。「・・・」「...」「…」単体は禁止 | 「……そうか」 |
| ダッシュ | 「――」を2個1組で使う。「-」「ー」で代用しない | 剣が――折れた。 |
| ！？ | 全角。組み合わせは「！？」の順。3連続以上は禁止 | 「はあ！？」 |
| ！？の後 | 文が続くなら全角スペース（閉じ括弧の直前は不要） | 「危ない！　逃げろ！」 |
| 会話文の句点 | 閉じ括弧の直前に句点を打たない | ×「そうだ。」→ ○「そうだ」 |
| 数字 | 漢数字を基本。桁の多いものは算用数字。作品内で統一 | 三人、十年前 |
| ルビ | `|漢字《ルビ》` 記法。固有名詞の初出のみ | `|竜殺《ドラゴンスレイヤー》` |

### 漢字をひらく語（迷ったらひらく）

事→こと／物（形式名詞）→もの／時→とき／所→ところ／為→ため／様だ→ようだ／通り→とおり／位・程→くらい・ほど／等→など／達→たち／出来る→できる／居る→いる／無い（補助）→ない／良い→いい／下さい→ください／頂く→いただく／〜て行く・来る→〜ていく・くる／〜て見る→〜てみる／更に→さらに／既に→すでに／沢山→たくさん／流石→さすが／何故→なぜ／是非→ぜひ

### 語彙の水準

- 中学生がふりがな無しで読める語だけを使う
- 硬い語・文語は禁止：「判じる」「静謐」「慟哭」「刹那」「須臾」「たまゆら」「〜せし」など
- かっこいい表現を思いついたら、それは削る合図

## 5. 改行と段落

- **1段落は1〜3文。**4文になったら必ず分割する
- 一文は**60字以内**。超えたら二文に割る
- 会話の応酬は1行ずつ改行する
- 間・時間経過・緊張の直前に空行を1行入れる。空行を2行以上連続させない
- 紙の小説のような「ぎっしり詰まった画面」を作らない

## 6. 会話文

- 台詞は「　」で独立した行にする。**会話が全体の5割前後**を占めるようにする
- 台詞が3往復以上続いたら、動作の地の文を1行挟んで話者を示す
- **説明台詞の禁止**：登場人物同士が知っている情報を読者向けに話させない
- 台詞の直後に「と言った」「と答えた」を毎回書かない。動作で受ける
- 役割語（「〜ですわ」「〜じゃよ」）はキャラ付けとして意図した場合のみ

## 7. 文の組み立て（読点と語順）

- 一文の読点「、」は**2個まで**。3個必要になったら文を割る
- **主語の直後に読点を打つ文（「隊長は、〜」「男が、〜」）は15行に2回まで。**原則、主語からそのまま述語へ続ける
- 語順は「誰が（いつ・どこで）何をした」。倒置（「来た、夜が。」）は禁止
- 連用中止の三連（「膨らみ、うねり、跳ねる」）は1話1回まで
- 同じ文末を3連続させない。文末「〜ていた」は15行に4回まで

## 8. 数値予算表（このスタイルの根幹）

「うまく書こう」とした瞬間に文章は崩れる。予算を超えた装飾は、出来に関係なく削る。

| 装置 | 上限 | 超えたときの直し方 |
|---|---|---|
| 直喩（「ように／ような／みたいに」の例え） | **1話2回** | 例えを消して事実だけ書く |
| 体言止め | 1シーン2回 | 述語を足す |
| 20字未満の演出段落（「なのに。」「静かだ。」等の一行） | **1話3回** | 前後の段落につなげる |
| 転調句（「そのときだった」「次の瞬間」「ふいに」） | 1話2回 | 消して、いきなり出来事を書く |
| 静寂の演出（「沈黙が落ちた」「静まり返った」） | 1話1回 | 会話か動作で場をつなぐ |
| フリーズ芝居（「言葉を失う」「動けなかった」「呆然」「絶句」） | 1話2回 | 小さい具体的な動作に置き換える |
| 小物ショットで段落やシーンを締める（「茶は冷めていた」型） | 1話1回 | 人物の動作か台詞で締める |
| 「――」 | 1話4回 | |
| 「……」 | 15行に3回 | |
| （　）書きの内心 | 1話2回 | |
| 「のだった」 | 1話1回 | |

## 9. 禁止表現リスト（書いたら必ず書き直す）

- 「まるで〜のよう」（「まるで」自体を禁止）
- 「そう、〜なのだ」
- 「だが、それは間違いだった」「このときの俺はまだ知らない」型の予告（1作品に数回の切り札。連発禁止）
- 「〜と言っても過言ではない」「〜せずにはいられなかった」
- 「運命が動き出す」「物語は始まったばかり」
- 「瞳に決意の色が宿る」「空気が張り詰める」「心臓が跳ねる」「息を呑む」などの常套句（合計で1話2回まで）
- 「〜なのか、〜なのか」の二択疑問文（1話1回まで）
- シーン末・話末での要約や教訓（「こうして俺の新しい生活が始まった」で締めない）
- 一人称なのに地の文で「彼」「彼女」を多用する（名前か役割で呼ぶ）
- 修飾語の三連鎖（「美しく荘厳で神秘的な」）
- 翻訳調：「〜することができる」→「〜できる」、「〜という事実」→「〜こと」
- 副詞の乱発：「ゆっくりと」「静かに」「まっすぐに」は各1話2回まで
- 感情の単語書き（「悲しかった」「怖かった」）で文を終えない。体感か動作を1つ添える

## 10. 各話の構成

- 1話は2,000〜4,000字
- **冒頭3行以内に台詞か動作**を置く。天気・風景・世界観説明から始めない
- 各話のラストは引きで終える（新しい疑問／危機／宣言／不穏な一言）
- 話タイトルは内容が想像できる具体的なものにする
- 1話でやることは1つ。「この話で何が変わるか」を一言で言えない話は書かない

## 11. 書いたあとの機械チェック（全部やる。感覚でOKを出さない）

本文を検索して、数える。

1. 「ように」「ような」「みたい」→ 合計2回以内か
2. 「まるで」→ 0か
3. 「そのとき」「次の瞬間」「ふいに」「不意に」→ 合計2回以内か
4. 「沈黙」「静寂」「静まり」→ 合計1回以内か
5. 「言葉を失」「動けな」「呆然」「絶句」「息を呑」「心臓」→ 合計2回以内か
6. 「のだった」→ 1回以内か
7. 読点が3個以上ある文 → 割る
8. 「は、」「が、」で始まる文 → 15行に2回以内か
9. 4文以上の段落 → 分割する
10. 20字未満の一行段落 → 3回以内か
11. 会話文の閉じ括弧直前の句点 → 0か
12. 同じ文末の3連続 → ないか
13. 冒頭3行に台詞か動作があるか／ラストに引きがあるか
14. 会話が5割前後あるか

## 12. 文体アンカー（この密度・テンポ・軽さに合わせる）

語彙の水準・改行の頻度・会話と地の文の比率を、以下に合わせる。

> 「――止まれ。おかしい」
>
> 村の門をくぐったところで、俺は二人を手で制した。
>
> 結界が薄い。いつもなら肌にまとわりつく膜みたいな手応えが、ここにはほとんどない。
>
> 「気づいたか」
>
> 副長のガルドがにやりと笑った。こいつがこの顔をするときは、だいたい面倒ごとが待っている。
>
> 「気づくさ。だから俺が呼ばれたんだろ」
> 「ご名答。手前の村までは普通に張ってあった。ここだけだ」
>
> 後ろでリタが荷袋を抱え直した。回復役のくせに、うちの隊でいちばんの怖がりだ。
>
> 「あの……静かすぎませんか？」
> 「村の夜なんてこんなもんだ」
>
> 口ではそう言ったが、正直、同感だった。虫の声ひとつしない。
