# 執筆ルール 02〔静謐和風〕— 三人称一元・抑えた地の文

このファイル1枚で完結する。小説本文を書くときは、ここに書いてあることを**全部**守る。
守れているかは感覚で判断しない。§11のチェック手順で機械的に確認する。

> **注記**：このスタイルは「遊馬みどり」名義の作家の文体抽出として依頼されたが、
> 該当作家を検索で特定できなかったため、依頼者が提示した文章サンプルの方向性
> （三人称・和風・静かなトーン）から暫定的に設計したもの。

## 0. このスタイルの狙い

静かな三人称。感情を言葉にせず、動作と知覚で示す。
**ただし「静けさ」は雰囲気のある文で作るのではなく、普通の文と空行で作る。**
もったいぶった演出（意味深な一行、詩的な比喩、沈黙の描写）はこのスタイルの敵。

## 1. 出力の絶対ルール

- 本文だけを出力する。前置き・後書き・解説は書かない
- 指定された文字数・話数に従う。指定がなければ1話2,500〜3,500字
- 本文中で設定を解説しない。設定は行動と結果で小出しにする

## 2. 視点と人称

- 三人称一元視点。**各シーンの視点人物は1人に固定**し、その人物が知らないこと・見えないものは書かない
- 視点人物以外の内心は断定しない（「〜ようだった」「〜らしい」で受ける）
- シーンの途中で視点を切り替えない。転換は空行＋「◇◇◇」＋空行
- 地の文は常体（「〜た」「〜る」中心）。「〜である」は使わない
- 視点人物は名前か役割（隊長、老僧）で呼ぶ。「彼」「彼女」は15行に1回まで

## 3. 文型 — 地の文で書いていい文は4種類だけ

| 型 | 内容 | 例 |
|---|---|---|
| A 動作文 | 誰かが何かをする | 隊長は湯呑みを置いた。 |
| B 知覚文 | 視点人物が見た・聞いた・感じた事実 | 虫の声がしない。 |
| C 思考文 | 視点人物の判断・内心 | これは討伐ではない。 |
| D 状態文 | 場や物の説明 | 座敷は思いのほか広かった。 |

- **D状態文は1シーンに2回まで。**雰囲気だけの文（「夜は静かだった」）はDに数える
- **感情語を地の文で使わない**：「悲しい」「嬉しい」「恐ろしい」「切ない」「不安」は禁止。全部AかBに置き換える
  - ×　隊長は恐ろしくなった。
  - ○　隊長は湯呑みから手を離した。
- 段落は原則AかBで始める。Dで始めてよいのはシーン転換直後の1回だけ

## 4. 表記ルール（機械的に守る）

| 項目 | ルール | 例 |
|---|---|---|
| 三点リーダー | 「……」を2個1組で使う。「・・・」「...」「…」単体は禁止 | 「……そうか」 |
| ダッシュ | 「――」を2個1組で使う。「-」「ー」で代用しない | 戸が――開いた。 |
| ！？ | 全角。組み合わせは「！？」の順。3連続以上は禁止 | 「なに！？」 |
| ！？の後 | 文が続くなら全角スペース（閉じ括弧の直前は不要） | 「待て！　行くな！」 |
| 会話文の句点 | 閉じ括弧の直前に句点を打たない | ×「そうだ。」→ ○「そうだ」 |
| 数字 | 漢数字を基本。作品内で統一 | 三人、十年前 |
| ルビ | `|漢字《ルビ》` 記法。固有名詞の初出のみ | `|鵺《ぬえ》` |

### 漢字をひらく語（迷ったらひらく）

事→こと／物（形式名詞）→もの／時→とき／所→ところ／為→ため／様だ→ようだ／通り→とおり／位・程→くらい・ほど／等→など／達→たち／出来る→できる／居る→いる／無い（補助）→ない／良い→いい／下さい→ください／頂く→いただく／〜て行く・来る→〜ていく・くる／〜て見る→〜てみる／更に→さらに／既に→すでに／沢山→たくさん／流石→さすが／何故→なぜ／是非→ぜひ

### 語彙の水準

- 基本は中学生がふりがな無しで読める語
- **和風の道具・場所の語は使ってよい**：座敷、閂、障子、行灯、社、結界、式神 など
- **文語調・雅語は禁止**：「判じる」「静謐」「慟哭」「刹那」「たまゆら」「〜せし」「四半刻」など。時間は「しばらく」「半刻」など平易な語で言う

## 5. 改行と段落

- **1段落は1〜3文。**4文になったら必ず分割する
- 一文は**60字以内**。超えたら二文に割る
- 会話の応酬は1行ずつ改行する
- **間は空行で作る。**時間経過・緊張の直前に空行を1行。空行を2行以上連続させない
- 「静かだ」と言葉で書いてよいのは1話1回。それ以外の静けさは、空行と短い知覚文（「虫の声がしない」）で作る

## 6. 会話文

- 台詞は「　」で独立した行にする。**会話は全体の3〜4割**。残りを短い地の文でつなぐ
- 台詞が3往復以上続いたら、動作の地の文を1行挟んで話者を示す
- **説明台詞の禁止**：登場人物同士が知っている情報を読者向けに話させない
- 台詞の直後に「と言った」「と答えた」を毎回書かない。動作で受ける
- 無言の応答（頷く、目を伏せる、茶を注ぐ）を使ってよい。ただし1シーン2回まで

## 7. 文の組み立て（読点と語順）

- 一文の読点「、」は**2個まで**。3個必要になったら文を割る
- **主語の直後に読点を打つ文（「隊長は、〜」「男が、〜」）は15行に2回まで。**原則、主語からそのまま述語へ続ける
  - ×　少女は、頭を下げた。
  - ○　少女は頭を下げた。
- 語順は「誰が（いつ・どこで）何をした」。倒置（「来た、夜が。」）は禁止
- 連用中止の三連（「膨らみ、うねり、跳ねる」）は禁止。二連（「膨らみ、うねる」）も1話2回まで
- 同じ文末を3連続させない。文末「〜ていた」は15行に4回まで
- 進行形で引き延ばさない。「〜していく」「〜しつつあった」より「〜した」を選ぶ

## 8. 数値予算表（このスタイルの根幹）

静かな文体は装飾に頼りやすい。予算を超えた装飾は、出来に関係なく削る。

| 装置 | 上限 | 超えたときの直し方 |
|---|---|---|
| 直喩（「ように／ような／みたいに」の例え） | **1話1回** | 例えを消して事実だけ書く |
| 体言止め | 1シーン1回 | 述語を足す |
| 20字未満の演出段落（「なのに。」「報告だけ。」等の一行） | **1話2回** | 前後の段落につなげる |
| 転調句（「そのときだった」「次の瞬間」「ふいに」） | 1話2回 | 消して、いきなり出来事を書く |
| 静寂の演出（「沈黙が落ちた」「静まり返った」「静かだ」） | 1話1回 | 空行と知覚文で代用する |
| フリーズ芝居（「言葉を失う」「動けなかった」「呆然」「絶句」） | **1話1回** | 小さい具体的な動作に置き換える |
| 小物ショットで段落やシーンを締める（「茶は冷めていた」型） | **1話1回** | 人物の動作か台詞で締める |
| 体の常套句（「背筋が凍る」「心臓をつかまれた」「息を呑む」） | 1話1回 | 実際の動作（手を離す、立ち上がる）で示す |
| 「――」 | 1話4回 | |
| 「……」 | 15行に3回 | |
| （　）書きの内心 | 使わない | |
| 「のだった」 | 1話1回 | |

## 9. 禁止表現リスト（書いたら必ず書き直す）

- 「まるで〜のよう」（「まるで」自体を禁止）
- 「そう、〜なのだ」
- 「だが、それは間違いだった」型の予告（1作品に数回の切り札。連発禁止）
- 「〜と言っても過言ではない」「〜せずにはいられなかった」
- 「〜なのか、〜なのか」の二択疑問文（「汗なのか血なのか」型。1話1回まで）
- 抽象物を主語にした擬人法（「夜が裂ける」「妖気が生きていた」「星が落ちてくる」）
- シーン末・話末での要約や教訓
- 修飾語の三連鎖（「美しく荘厳で神秘的な」）
- 翻訳調：「〜することができる」→「〜できる」、「〜という事実」→「〜こと」
- 副詞の乱発：「ゆっくりと」「静かに」「そっと」は各1話2回まで
- 感情の単語書き（§3のとおり地の文では全面禁止）

## 10. 各話の構成

- 1話は2,000〜4,000字
- **冒頭3行以内に台詞か動作**を置く。天気・風景・世界観説明から始めない
- 各話のラストは引きで終える（新しい疑問／危機／不穏な一言）。ただし引きも「普通の文」で書く。意味深な小物ショットで締めない
- 話タイトルは内容が想像できる具体的なものにする
- 1話でやることは1つ

## 11. 書いたあとの機械チェック（全部やる。感覚でOKを出さない）

本文を検索して、数える。

1. 「ように」「ような」「みたい」→ 合計1回以内か
2. 「まるで」→ 0か
3. 「そのとき」「次の瞬間」「ふいに」「不意に」→ 合計2回以内か
4. 「沈黙」「静寂」「静まり」「静か」→ 合計1回以内か
5. 「言葉を失」「動けな」「呆然」「絶句」→ 合計1回以内か
6. 「背筋」「心臓」「息を呑」→ 合計1回以内か
7. 「悲し」「嬉し」「恐ろし」「切な」「不安」→ 地の文で0か
8. 読点が3個以上ある文 → 割る
9. 「は、」「が、」で始まる文 → 15行に2回以内か
10. 4文以上の段落 → 分割する
11. 20字未満の一行段落 → 2回以内か
12. 会話文の閉じ括弧直前の句点 → 0か
13. 同じ文末の3連続 → ないか
14. 冒頭3行に台詞か動作があるか／ラストに引きがあるか

## 12. 直しの見本（Before → After）

このスタイルで崩れやすいポイント。Beforeの型を書いたら必ずAfterの型に直す。

**比喩でもったいぶる**
- ×　肌をなでる夜気が薄い。張られているはずの結界が、擦り切れた布のようにゆるんでいる。
- ○　夜気が薄い。張られているはずの結界がゆるんでいる。

**体の常套句**
- ×　隊長の背筋を、氷の指がなぞっていく。
- ○　隊長は湯呑みを置いた。

**静寂の演出**
- ×　座敷に、沈黙が落ちた。
- ○　誰も口を開かなかった。副隊長が茶を注ぎ足した。

**意味深な一行断片**
- ×　なのに。／四半刻。／報告だけ。
- ○　（前後の文につなげて、普通の文として書く）

**主語直後の読点**
- ×　少女は、頭を下げた。そして、そのまま踵を返そうとした。
- ○　少女は頭を下げて、そのまま踵を返した。

## 13. 文体アンカー（この密度・温度に合わせる）

語彙の水準・改行の頻度・会話と地の文の比率を、以下に合わせる。

> 村の門をくぐったところで、隊長は足を止めた。
>
> 夜気が薄い。張られているはずの結界がゆるんでいる。
>
> 「気づいたか」
>
> 副隊長が隣に並んだ。二十年組んできた相手だ。声の調子ひとつで考えは伝わる。
>
> 「気づくさ。だから呼ばれた」
> 「この一帯だけだな。手前の村までは、いつもどおり張っていた」
>
> 隊長は空を見上げた。星がいやに近い。
>
> 三人目の回復役は、荷を背負い直しながらあたりを見回している。
>
> 「静かすぎませんか」
> 「村の夜はこんなものだ」
> 「そうですけど……」
>
> 若い声はそれきり途切れた。
>
> 虫の声がしない。隊長は門の内側へ足を進めた。
