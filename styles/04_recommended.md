# 執筆ルール 04〔推奨〕— 透明な文体＋最小限の味付け

このファイル1枚で完結する。小説本文を書くときは、ここに書いてあることを**全部**守る。
守れているかは感覚で判断しない。§11のチェック手順で機械的に確認する。

## 0. このスタイルの狙い

土台は03〔違和感ゼロ〕と同じ透明な文体。読者に文章を意識させない。
そこに、**厳しい予算つきで**少量の体温を足す。人柄は内心の声で、場面は五感で立ち上げる。
足すのは「読者が気づかない程度の味」まで。気づかれたら足しすぎ。

読みやすさと個性のバランスが最も良い。スタイル指定がない依頼はこれで書く。

## 1. 出力の絶対ルール

- 本文だけを出力する。前置き・後書き・解説は書かない
- 指定された文字数・話数に従う。指定がなければ1話2,500〜3,500字
- 本文中で設定を解説しない。設定は行動と結果で小出しにする

## 2. 視点と人称

- 一人称（俺／私）を基本とする。指定があれば三人称一元も可
- 作品開始時に決めた人称は絶対に変えない
- 視点人物が知らないこと・見えないものは書かない。他人の内心を断定しない（「〜ようだった」で受ける）
- シーンの途中で視点を切り替えない。転換は空行＋「◇◇◇」＋空行
- 地の文は常体（「〜た」「〜る」中心）。「〜である」は使わない
- 内心のツッコミ・ぼやき（「いや、無理だろ」）は地の文にそのまま書く。**15行に1回まで**

## 3. 文型 — 地の文で書いていい文は4種類だけ

| 型 | 内容 | 例 |
|---|---|---|
| A 動作文 | 誰かが何かをする | 俺は戸を開けた。 |
| B 知覚文 | 視点人物が見た・聞いた・感じた事実 | 土の匂いがした。 |
| C 思考文 | 視点人物の判断・内心 | 誰かいる。 |
| D 状態文 | 場や物の説明 | 台所に人はいなかった。 |

- **D状態文は1シーンに2回まで。**雰囲気だけの文（「夜は静かだった」）もDに数える
- **シーン転換の直後はB知覚文（音・匂い・温度・光のどれか1つ）で場面を立ち上げる。これは義務**
- 出来事は時系列順に書く。回想は1話1回まで、「〜を思い出した」と明示してから入る
- 段落は原則AかBで始める

## 4. 表記ルール（機械的に守る）

| 項目 | ルール | 例 |
|---|---|---|
| 三点リーダー | 「……」を2個1組で使う。「・・・」「...」「…」単体は禁止 | 「……そうか」 |
| ダッシュ | 「――」を2個1組で使う。「-」「ー」で代用しない | 剣が――折れた。 |
| ！？ | 全角。組み合わせは「！？」の順。3連続以上は禁止 | 「はあ！？」 |
| ！？の後 | 文が続くなら全角スペース（閉じ括弧の直前は不要） | 「危ない！　逃げろ！」 |
| 会話文の句点 | 閉じ括弧の直前に句点を打たない | ×「そうだ。」→ ○「そうだ」 |
| 数字 | 漢数字を基本。桁の多いものは算用数字。作品内で統一 | 三人、十年前 |
| ルビ | `|漢字《ルビ》` 記法。固有名詞の初出のみ | `|竜殺《ドラゴンスレイヤー》` |

### 漢字をひらく語（迷ったらひらく）

事→こと／物（形式名詞）→もの／時→とき／所→ところ／為→ため／様だ→ようだ／通り→とおり／位・程→くらい・ほど／等→など／達→たち／出来る→できる／居る→いる／無い（補助）→ない／良い→いい／下さい→ください／頂く→いただく／〜て行く・来る→〜ていく・くる／〜て見る→〜てみる／更に→さらに／既に→すでに／沢山→たくさん／流石→さすが／何故→なぜ／是非→ぜひ

### 語彙の水準

- 中学生がふりがな無しで読める語だけを使う
- 硬い語・文語・雅語は禁止：「判じる」「静謐」「慟哭」「刹那」「四半刻」「〜せし」など
- 同じ意味なら易しいほうの語を選ぶ（「凝視する」→「じっと見る」）

## 5. 改行と段落

- **1段落は1〜3文。**4文になったら必ず分割する
- 一文は**60字以内**。超えたら二文に割る
- 会話の応酬は1行ずつ改行する
- 間・時間経過・緊張の直前に空行を1行。空行を2行以上連続させない
- 短文の連打（5〜15字の文を続ける）は戦闘・緊迫シーンだけの武器。日常シーンでやらない

## 6. 会話文

- 台詞は「　」で独立した行にする。**会話は全体の4〜6割**
- 台詞が3往復以上続いたら、動作の地の文を1行挟んで話者を示す
- **説明台詞の禁止**：登場人物同士が知っている情報を読者向けに話させない
- 台詞の直後に「と言った」「と答えた」を毎回書かない。動作で受ける
- 役割語（「〜ですわ」「〜じゃよ」）はキャラ付けとして意図した場合のみ
- キャラの個性は地の文で説明せず、台詞の言い回しと行動の癖で出す

## 7. 文の組み立て（読点と語順）

- 一文の読点「、」は**2個まで**。3個必要になったら文を割る
- **主語の直後に読点を打つ文（「隊長は、〜」）は15行に2回まで。**原則、主語からそのまま述語へ続ける
- 語順は「誰が（いつ・どこで）何をした」。倒置は禁止
- 修飾語は1文に2個まで
- 連用中止の三連（「膨らみ、うねり、跳ねる」）は禁止
- 同じ文末を3連続させない。凝った言い換えをするくらいなら、1文をB知覚文に変えるだけでいい
- 進行形で引き延ばさない。「〜していく」「〜しつつあった」より「〜した」
- 擬音は地の文では1シーン1回まで

## 8. 数値予算表（このスタイルの根幹）

03との違いはこの表の数字だけ。予算内の装飾は使ってよいが、使い切る義務はない。

| 装置 | 上限 | 補足 |
|---|---|---|
| 直喩（「ように／ような」の例え） | **1話1回** | 目に見える具体物への例えのみ（「膜のような」は可、「運命のような」は不可） |
| 体言止め | 1シーン1回 | |
| 20字未満の演出段落（「まずい。」等の一行） | **1話2回** | |

| フリーズ芝居（「言葉を失う」「動けなかった」「呆然」「絶句」） | **1話1回** | 小さい具体的な動作が基本 |

| 体の常套句（「背筋が凍る」「心臓が跳ねる」「息を呑む」） | 1話1回 | |
| 擬人法（「夜が裂ける」「妖気が生きている」） | 0回 | |
| 「――」 | 1話4回 | |
| 「……」 | 15行に3回 | |
| （　）書きの内心 | 1話1回 | |
| 「のだった」 | 0回 | |

## 9. 禁止表現リスト（書いたら必ず書き直す）

- 「まるで」「あたかも」「さながら」
- 「そう、〜なのだ」
- 「だが、それは間違いだった」「このときはまだ知らない」型の予告（1作品に数回の切り札。連発禁止）
- 「〜と言っても過言ではない」「〜せずにはいられなかった」
- 「運命が動き出す」「物語は始まったばかり」
- 「〜なのか、〜なのか」の二択疑問文（1話1回まで）
- シーン末・話末での要約や教訓（「こうして俺の新しい生活が始まった」で締めない）
- 一人称なのに地の文で「彼」「彼女」を多用する（名前か役割で呼ぶ）
- 修飾語の三連鎖（「美しく荘厳で神秘的な」）
- 翻訳調：「〜することができる」→「〜できる」、「〜という事実」→「〜こと」
- 副詞の乱発：「ゆっくりと」「静かに」「まっすぐに」は各1話2回まで
- 感情の単語書き（「悲しかった」「怖かった」）で文を終えない。体感か動作を1つ添える

## 10. 各話の構成

- 1話は2,000〜4,000字
- **冒頭3行以内に台詞か動作**を置く。天気・風景・世界観説明から始めない
- 各話のラストは引きで終える（新しい疑問／危機／宣言／不穏な一言）。引きも普通の文で書く
- 話タイトルは内容が想像できる具体的なものにする
- 1話でやることは1つ。「この話で何が変わるか」を一言で言えない話は書かない

## 11. 書いたあとの機械チェック（全部やる。感覚でOKを出さない）

本文を検索して、数える。

1. 「ように」「ような」「みたい」→ 合計1回以内か
2. 「まるで」「あたかも」「さながら」→ 0か
3. 「そのとき」「次の瞬間」「ふいに」「不意に」→ 合計1回以内か
4. 「沈黙」「静寂」「静まり」→ 0か
5. 「言葉を失」「動けな」「呆然」「絶句」→ 合計1回以内か
6. 「背筋」「心臓」「息を呑」→ 合計1回以内か
7. 「のだった」→ 0か
8. 読点が3個以上ある文 → 割る
9. 「は、」「が、」で始まる文 → 15行に2回以内か
10. 4文以上の段落 → 分割する
11. 20字未満の一行段落 → 2回以内か
12. 会話文の閉じ括弧直前の句点 → 0か
13. 同じ文末の3連続 → ないか
14. シーン転換直後に五感（音・匂い・温度・光）が1つあるか
15. 冒頭3行に台詞か動作があるか／ラストに引きがあるか

## 12. 文体アンカー（この密度・温度に合わせる）

語彙の水準・改行の頻度・会話と地の文の比率を、以下に合わせる。
長い見本は `samples/fantasy_sample.md` にある。

> 「――止まれ」
>
> 村の門をくぐったところで、俺は足を止めた。夜気が薄い。張ってあるはずの結界がゆるんでいる。
>
> 「気づいたか」
>
> 副長が隣に並んだ。二十年来の相棒だ。短い言葉で足りる。
>
> 「気づくさ。だから呼ばれた」
> 「この一帯だけだ。手前の村までは普通に張ってあった」
>
> 後ろで回復役のリタが荷を背負い直した。
>
> 「静かすぎませんか」
> 「村の夜はこんなもんだ」
>
> 口ではそう答えた。だが、たしかに静かすぎる。虫の声ひとつしない。
>
> 土の匂いだけが、やけに濃かった。
