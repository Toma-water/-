# 執筆ルール 03〔違和感ゼロ〕— 透明な文体

このファイル1枚で完結する。小説本文を書くときは、ここに書いてあることを**全部**守る。
守れているかは感覚で判断しない。§11のチェック手順で機械的に確認する。

## 0. このスタイルの狙い

目標はただ一つ。**読者に文章の存在を意識させないこと。**
読者が覚えているのは「何が起きたか」だけでいい。文章が褒められる必要はない。
「いい文が書けた」と感じたら、それはこのスタイルでは事故。普通の文に直す。

4つのスタイルの中で最も制約が強い。そのぶん、どのAIに書かせても同じ文になる。

## 1. 出力の絶対ルール

- 本文だけを出力する。前置き・後書き・解説は書かない
- 指定された文字数・話数に従う。指定がなければ1話2,500〜3,500字
- 本文中で設定を解説しない。設定は行動と結果で小出しにする

## 2. 視点と人称

- 人称は作品ごとの指定に従う。指定がなければ一人称（俺／私）
- 三人称の場合は一元視点。各シーンの視点人物は1人に固定する
- 視点人物が知らないこと・見えないものは書かない。他人の内心を断定しない（「〜ようだった」で受ける）
- シーンの途中で視点を切り替えない。転換は空行＋「◇◇◇」＋空行
- 地の文は常体（「〜た」「〜る」中心）。「〜である」は使わない

## 3. 文型 — 地の文で書いていい文は4種類だけ

| 型 | 内容 | 例 |
|---|---|---|
| A 動作文 | 誰かが何かをする | 俺は戸を開けた。 |
| B 知覚文 | 視点人物が見た・聞いた・感じた事実 | 奥で水の音がした。 |
| C 思考文 | 視点人物の判断・内心 | 誰かいる。 |
| D 状態文 | 場や物の説明 | 台所に人はいなかった。 |

- **D状態文は1シーンに2回まで。**雰囲気だけの文（「夜は静かだった」「空気が重い」）もDに数える
- 出来事は**時系列順**に書く。あとから「実はその前に〜」とやらない
- 回想は1話1回まで。入るときは「〜を思い出した」と明示してから入る
- 段落は必ずAかBで始める。Dで始めてよいのはシーン転換直後の1回だけ

## 4. 表記ルール（機械的に守る）

| 項目 | ルール | 例 |
|---|---|---|
| 三点リーダー | 「……」を2個1組で使う。「・・・」「...」「…」単体は禁止 | 「……そうか」 |
| ダッシュ | 「――」を2個1組。ただしこのスタイルでは台詞の中断のみに使う | 「待て、それは――」 |
| ！？ | 全角。組み合わせは「！？」の順。3連続以上は禁止 | 「はあ！？」 |
| ！？の後 | 文が続くなら全角スペース（閉じ括弧の直前は不要） | 「危ない！　逃げろ！」 |
| 会話文の句点 | 閉じ括弧の直前に句点を打たない | ×「そうだ。」→ ○「そうだ」 |
| 数字 | 漢数字を基本。作品内で統一 | 三人、十年前 |
| ルビ | `|漢字《ルビ》` 記法。固有名詞の初出のみ | `|竜殺《ドラゴンスレイヤー》` |

### 漢字をひらく語（迷ったらひらく）

事→こと／物（形式名詞）→もの／時→とき／所→ところ／為→ため／様だ→ようだ／通り→とおり／位・程→くらい・ほど／等→など／達→たち／出来る→できる／居る→いる／無い（補助）→ない／良い→いい／下さい→ください／頂く→いただく／〜て行く・来る→〜ていく・くる／〜て見る→〜てみる／更に→さらに／既に→すでに／沢山→たくさん／流石→さすが／何故→なぜ／是非→ぜひ

### 語彙の水準

- 中学生がふりがな無しで読める語**だけ**を使う
- 硬い語・文語・雅語は禁止：「判じる」「静謐」「慟哭」「刹那」「四半刻」「〜せし」など
- 同じ意味なら、必ず易しいほうの語を選ぶ（「凝視する」→「じっと見る」）

## 5. 改行と段落

- **1段落は1〜3文。**4文になったら必ず分割する
- 一文は**50字以内**（他スタイルより短い）。超えたら二文に割る
- 会話の応酬は1行ずつ改行する
- 時間経過・場面の区切りに空行を1行。空行を2行以上連続させない

## 6. 会話文

- 台詞は「　」で独立した行にする。**会話は全体の4〜5割**
- 台詞が3往復以上続いたら、動作の地の文を1行挟んで話者を示す
- **説明台詞の禁止**：登場人物同士が知っている情報を読者向けに話させない
- 台詞の直後に「と言った」「と答えた」を毎回書かない。動作で受ける
- 役割語（「〜ですわ」「〜じゃよ」）はキャラ付けとして意図した場合のみ

## 7. 文の組み立て（読点と語順）

- 一文の読点「、」は**2個まで**。3個必要になったら文を割る
- **主語の直後に読点を打つ文（「隊長は、〜」）は15行に1回まで。**原則、主語からそのまま述語へ続ける
- 語順は「誰が（いつ・どこで）何をした」に固定。倒置は禁止
- 修飾語は1文に2個まで。副詞は削って意味が変わるときだけ使う
- 連用中止の三連（「膨らみ、うねり、跳ねる」）は禁止
- 同じ文末の3連続は避ける。ただし**凝った言い換えをするくらいなら「た」の連続のほうがまし。**3連続したら1文をB知覚文（「〜がする」「〜が見える」）に変えるだけでいい
- 進行形で引き延ばさない。「〜していく」「〜しつつあった」より「〜した」
- 擬音は地の文では1シーン1回まで

## 8. 数値予算表（このスタイルの根幹）

透明な文体に装飾はいらない。以下はほぼ全部禁止。

| 装置 | 上限 | 超えたときの直し方 |
|---|---|---|
| 直喩（「ように／ような／みたいに」の例え） | **0回** | 例えを消して事実だけ書く |
| 体言止め | **0回** | 述語を足す |
| 20字未満の演出段落（「なのに。」等の一行） | **1話1回**（0が望ましい） | 前後の段落につなげる |
| 転調句（「そのときだった」「次の瞬間」「ふいに」） | **1話1回** | 消して、いきなり出来事を書く |
| 静寂の演出（「沈黙が落ちた」「静まり返った」） | **0回** | 「誰も口を開かなかった」等のA/B文で書く |
| フリーズ芝居（「言葉を失う」「動けなかった」「呆然」「絶句」） | **0回** | 小さい具体的な動作に置き換える |
| 小物ショットで段落やシーンを締める（「茶は冷めていた」型） | **0回** | 人物の動作か台詞で締める |
| 体の常套句（「背筋が凍る」「心臓が跳ねる」「息を呑む」） | **0回** | 実際の動作で示す |
| 擬人法（「夜が裂ける」「妖気が生きている」） | **0回** | 事実として観察できることだけ書く |
| 「――」（台詞の中断以外の用途） | 0回 | |
| 「……」 | 15行に2回 | |
| （　）書きの内心 | 使わない | |
| 「のだった」 | 0回 | |

## 9. 禁止表現リスト（書いたら必ず書き直す）

- 「まるで」「あたかも」「さながら」
- 「そう、〜なのだ」
- 「だが、それは間違いだった」「このときはまだ知らない」型の予告（全面禁止）
- 「〜と言っても過言ではない」「〜せずにはいられなかった」
- 「〜なのか、〜なのか」の二択疑問文（全面禁止）
- シーン末・話末での要約や教訓
- 修飾語の三連鎖（「美しく荘厳で神秘的な」）
- 翻訳調：「〜することができる」→「〜できる」、「〜という事実」→「〜こと」
- 感情の単語書き（「悲しかった」「怖かった」）で文を終えない。体感か動作を1つ添える
- 一人称なのに地の文で「彼」「彼女」を多用する（名前か役割で呼ぶ）

## 10. 各話の構成

- 1話は2,000〜4,000字
- **冒頭3行以内に台詞か動作**を置く。天気・風景・世界観説明から始めない
- 各話のラストは引きで終える（新しい疑問／危機／宣言／不穏な一言）。引きも普通の文で書く
- 話タイトルは内容が想像できる具体的なものにする
- 1話でやることは1つ

## 11. 書いたあとの機械チェック（全部やる。感覚でOKを出さない）

本文を検索して、数える。

1. 「ように」「ような」「みたい」→ **0か**（「〜するように言った」等の用法も避ける）
2. 「まるで」「あたかも」「さながら」→ 0か
3. 「そのとき」「次の瞬間」「ふいに」「不意に」→ 合計1回以内か
4. 「沈黙」「静寂」「静まり」→ 0か
5. 「言葉を失」「動けな」「呆然」「絶句」「息を呑」「心臓」「背筋」→ 0か
6. 「のだった」→ 0か
7. 読点が3個以上ある文 → 割る
8. 「は、」「が、」で始まる文 → 15行に1回以内か
9. 50字を超える文 → 割る
10. 4文以上の段落 → 分割する
11. 20字未満の一行段落 → 1回以内か
12. 会話文の閉じ括弧直前の句点 → 0か
13. 体言止め（名詞で終わる文）→ 0か
14. 冒頭3行に台詞か動作があるか／ラストに引きがあるか

## 12. 文体アンカー（この「何もなさ」に合わせる）

うまく見せようとした跡が一つもないこと。それがこのスタイルの完成形。

> 村の門をくぐったところで、隊長は足を止めた。
>
> 結界が薄い。手前の村で感じた圧が、ここにはない。
>
> 「気づいたか」
>
> 副隊長が隣に並んだ。二十年組んできた相手だ。短い言葉で足りる。
>
> 「気づくさ。だから呼ばれた」
> 「この一帯だけだ。手前の村までは普通に張ってあった」
>
> 回復役の若い女が荷を背負い直して、あたりを見回した。
>
> 「静かすぎませんか」
> 「村の夜はこんなものだ」
>
> 隊長はそう答えた。だが、たしかに虫の声がしない。
>
> 三人は門の内側へ進んだ。
