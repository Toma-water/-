# GFRP ボディ用 型(3Dプリント用CAD)

GFRP を**外側に巻いて**作る円筒ボディ用の雄型(マンドレル)です。

| 項目 | 値 |
|------|-----|
| 完成ボディ内径(= GFRP 内径 = 型外径) | **φ90 mm** |
| 完成狙い高さ | 60 mm |
| 型の高さ(余裕込み) | **80 mm**(上端 20 mm はトリミング代) |
| 出力単位 | mm(Bambu Studio にそのままインポート可) |

> 成功基準=「型を抜くときに硬化した GFRP の形が崩れないこと」。
> これに対して **抜き方の異なる3案**を用意しました。用途に合わせて選んでください。

---

## 3つの案

### 案1 `1_breakaway_mandrel.stl` — 壊して剥がす(使い捨て)
- φ90・高さ80 の**薄肉カップ(壁2.5mm)**+ 底フランジ。内壁に**割れ起点の縦Vノッチ6本**入り。
- GFRP 硬化後、内側からプライヤー等で潰して割り、破片を取り出す。
- **長所**: 形状が一番自由・確実に抜ける。**短所**: 1個1回限り。
- ご要望の「壊して剥がす」案です。

### 案2 `2_taper_mandrel.stl` — テーパー(抜き勾配)で引き抜く【再利用可・簡単】
- **片側1°の抜き勾配**付きマンドレル(下φ90 → 上φ約87.2)+ 底フランジ。中空シェル。
- 離型剤を塗って巻き、硬化後に上方向へスポッと引き抜く(上ほど細いので抜ける)。
- **長所**: 再利用でき、構造が単純。**短所**: ボディ内面がわずかにテーパーになる(完全な真円筒ではない)。

### 案3 `3_collapsible_*.stl` — キーストーン式コラプシブル中子型【真円筒・真空対応・本命】
**真円筒必須・真空引きあり**の条件に合わせた設計です。図解は `figs/` を参照。

- 構成パーツ(計6点):
  - `3_collapsible_keystone.stl` … キーストーン(60°の楔、最初に上へ抜く)×1
  - `3_collapsible_segment_1of3.stl`〜`_3of3.stl` … 100°セグメント ×3
  - `3_collapsible_center_key.stl` … センターキー/中子(テーパー嵌合・引抜きノブ付き)×1
  - `3_collapsible_base_plate.stl` … 位置決めベース ×1

- **真円筒(隙間ゼロ)**: 外周は4ピース(キーストーン+3セグメント)が**隙間ゼロで突き合わさり**、完全な φ90 円筒になります(合計360°、逃げ隙間なし)。前バージョンのような分割隙間はありません。
- **真空引き対策**: 真空圧は積層材を内側(型側)へ押します。中空のままだとセグメントが内側へ潰れて真円が崩れるため、**センターキー(中子)を中央テーパー穴に差し込んで内側から支え**、真円筒を保持します。表面は離型フィルムを一周巻いて目地(継ぎ目)を塞ぎ、真空のリーク・段差を防ぎます(下記)。

- **抜く手順**(図 `figs/fig4_sequence.png`):
  1. 真空解除・硬化後、**センターキーを上へ引き抜く**(中央に逃げ空間ができる)
  2. **キーストーンを上へ引き抜く**(上端のφ5穴にネジ/フックを掛けて引く)
  3. 残り3セグメントを中央側へ寄せて GFRP から離し、軸方向に抜く
- **長所**: 真円筒・再利用可・真空対応・GFRP を変形させずに抜ける(基準を最も満たす)。**短所**: 組立式で手間。

## 共通の離型のコツ(形を崩さない & 真空リーク防止のため重要)
- どの案でも、型表面に**離型処理**をしてから巻く:離型ワックス+PVA離型剤、または**梱包用PPテープ/離型フィルム(または薄いPP/FEPスリーブ)を一周**貼る。
- **案3+真空引きの場合は特に**、組み立てた型全体に**離型フィルムを一周**巻くと、継ぎ目(隙間ゼロだが髪の毛一本の目地)が完全に塞がり、真空のリークや表面段差が出ません。フィルム自体が連続した滑らかな成形面になります。
- 案1・案2は表面の積層段差を軽く均す(高番手サンディング)とさらに剥がれやすい。

## Bambu Studio 設定の目安
| 案 | 素材 | 配置 | 壁 | インフィル | 備考 |
|----|------|------|----|-----------|------|
| 案1 breakaway | PLA(脆く割りやすい) | フランジ面を下 | 2 | 10〜15% | 割って捨てる前提 |
| 案2 taper | PLA / PETG | フランジ面を下 | 3〜4 | 15% | 外面の品質重視。層0.12〜0.16mm推奨 |
| 案3 keystone/segment | PLA / PETG | 底(z=0)面を下 | 3〜4 | 25〜30% | 真空圧で潰れぬよう剛性高め。外面の真円度重視 |
| 案3 center key | PLA / PETG | 小径側を下に**ブリム** | 3〜4 | 30% | 中子は真空圧を受けるので密度高め |
| 案3 base | PLA | そのまま | 3 | 20% | 位置決め用 |

- すべて単位は mm。インポート時にスケール変更は不要です。
- 案3 のセンターキーは細長いので**ブリム**を付けると安定します。
- 案3 は外面が成形面になるので、外周4ピースは**層0.12〜0.16mm**+壁多めで真円度・面品質を上げてください。

## 再生成・寸法変更
寸法は `make_molds.py` 冒頭の定数で変更できます(`D_INNER`, `H_BODY`, `H_MARGIN` など)。

```bash
pip install numpy trimesh manifold3d shapely
python3 make_molds.py      # stl/ に再出力
python3 preview.py         # 案1/2 と組立の簡易PNG(任意・matplotlib 必要)
python3 preview2.py        # 案3 の詳細図 figs/(分解・断面・上面・手順)
```

生成物は STL が `stl/`、図が `figs/` に出力されます。
