# GFRP ボディ用 型(3Dプリント用CAD)

GFRP を**外側に巻いて**作る円筒ボディ用の雄型(マンドレル)です。

| 項目 | 値 |
|------|-----|
| 完成ボディ内径(= GFRP 内径 = 型外径) | **φ90 mm** |
| 完成狙い高さ | 60 mm |
| 型の高さ(余裕込み) | **80 mm**(上端 20 mm はトリミング代) |
| 出力単位 | mm(Bambu Studio にそのままインポート可) |

> 成功基準=「型を抜くときに硬化した GFRP の形が崩れないこと」。
> これに対して **抜き方の異なる3案**を用意しました。用途に合わせて選んでください。

---

## 3つの案

### 案1 `1_breakaway_mandrel.stl` — 壊して剥がす(使い捨て)
- φ90・高さ80 の**薄肉カップ(壁2.5mm)**+ 底フランジ。内壁に**割れ起点の縦Vノッチ6本**入り。
- GFRP 硬化後、内側からプライヤー等で潰して割り、破片を取り出す。
- **長所**: 形状が一番自由・確実に抜ける。**短所**: 1個1回限り。
- ご要望の「壊して剥がす」案です。

### 案2 `2_taper_mandrel.stl` — テーパー(抜き勾配)で引き抜く【再利用可・簡単】
- **片側1°の抜き勾配**付きマンドレル(下φ90 → 上φ約87.2)+ 底フランジ。中空シェル。
- 離型剤を塗って巻き、硬化後に上方向へスポッと引き抜く(上ほど細いので抜ける)。
- **長所**: 再利用でき、構造が単純。**短所**: ボディ内面がわずかにテーパーになる(完全な真円筒ではない)。

### 案3 `3_collapsible_*.stl` — コラプシブル中子型【再利用可・真円筒・本命】
- 構成パーツ(計5点):
  - `3_collapsible_center_key.stl` … 中心キー(テーパー楔・引抜きノブ付き)×1
  - `3_collapsible_segment_1of3.stl`〜`_3of3.stl` … 外周120°セグメント ×3
  - `3_collapsible_base_plate.stl` … 位置決めベース ×1
- 外周は**ストレートのφ90(真円筒)**。抜く手順:
  1. 中心キーを上に引き抜く(中央に逃げ空間ができる)
  2. 各セグメントを内側へ寄せて GFRP から離す
  3. セグメントを軸方向に抜く
- **長所**: 真円筒・再利用可・GFRP を変形させずに抜ける(基準を最も満たす)。**短所**: 組立式で手間。

---

## 共通の離型のコツ(形を崩さないために重要)
- どの案でも、型表面に**離型処理**をしてから巻く:離型ワックス+PVA離型剤、または**梱包用PPテープ/離型フィルム**を一周貼る。
- 案1・案2は表面の積層段差を軽く均す(高番手サンディング)とさらに剥がれやすい。

---

## Bambu Studio 設定の目安
| 案 | 素材 | 配置 | 壁 | インフィル | 備考 |
|----|------|------|----|-----------|------|
| 案1 breakaway | PLA(脆く割りやすい) | フランジ面を下 | 2 | 10〜15% | 割って捨てる前提 |
| 案2 taper | PLA / PETG | フランジ面を下 | 3〜4 | 15% | 外面の品質重視。層0.12〜0.16mm推奨 |
| 案3 segment | PLA / PETG | 底(z=0)面を下 | 3〜4 | 20〜25% | 剛性が要るのでやや高め |
| 案3 key/base | PLA | キーは小径側を下に**ブリム**推奨 | 3 | 20% | テーパー寸法精度を重視 |

- すべて単位は mm。インポート時にスケール変更は不要です。
- 案3 のキーは細長いので**ブリム**を付けると安定します。

---

## 再生成・寸法変更
寸法は `make_molds.py` 冒頭の定数で変更できます(`D_INNER`, `H_BODY`, `H_MARGIN` など)。

```bash
pip install numpy trimesh manifold3d shapely
python3 make_molds.py      # stl/ に再出力
python3 preview.py         # 確認用 PNG を出力(任意・matplotlib 必要)
```

生成物は `stl/` に出力されます。
