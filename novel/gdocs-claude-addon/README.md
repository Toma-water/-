# Googleドキュメント用 Claude サイドバー

Googleドキュメントの中に、Gemini のような Claude のサイドバーを追加する Apps Script。
選択範囲をその場で書き換えられる。設定資料ドキュメントを常に文脈として読ませられるのが、
標準のAIアシスタントにない部分。

## できること

| 機能 | 内容 |
|---|---|
| 講評 | 選択範囲を読んで、弱い箇所を具体的に指摘する。本文は書き換えない |
| リライト | 選択範囲を指示通りに書き直し、**ドキュメント本文をその場で置換**する |
| 続き | カーソル位置から続きを書いて挿入する |
| 相談 | 原稿全体＋設定資料を踏まえて自由に相談する |

原稿の全文と、指定した設定資料ドキュメントの全文が、毎回自動で文脈に入る。
固有名詞や時系列の矛盾はそこで拾える。

## 導入手順

### 1. APIキーを取得する

<https://console.anthropic.com> でAPIキーを発行する（`sk-ant-` で始まる文字列）。

> **注意：これは Claude Pro / Max のサブスクリプションとは別の従量課金です。**
> サブスクに入っていてもAPI利用分は別途かかる。
> Claude Opus 5 は入力 $5 / 100万トークン、出力 $25 / 100万トークン。
> 原稿5万字＋設定資料2万字を毎回送っても1回あたり数円〜十数円程度だが、無料ではない。
> 設定資料は毎回同じ内容なのでプロンプトキャッシュが効くようにしてあり、
> 連続して使うぶんには入力コストが1割程度まで下がる。

### 2. スクリプトを貼る

1. 小説を書いている Google ドキュメントを開く
2. メニュー **拡張機能 ▸ Apps Script**
3. 開いたエディタの `コード.gs` の中身を全部消して、`Code.gs` の中身を貼り付ける
4. 左の **ファイル** の `+` ▸ **HTML** を選び、名前を `Sidebar`（`.html` は不要）にして、
   `Sidebar.html` の中身を貼り付ける
5. 保存（Ctrl+S / ⌘S）

### 3. 有効化する

1. ドキュメントのタブに戻ってリロードする
2. メニューに **Claude** が増えている
3. **Claude ▸ APIキーを設定** でキーを登録（初回は権限の承認を求められる。
   「詳細」▸「安全でないページに移動」から許可する。自作スクリプトなので未確認アプリ扱いになる）
4. **Claude ▸ 設定資料ドキュメントを指定** で、世界観・人物設定をまとめたドキュメントのURLを登録
5. **Claude ▸ サイドバーを開く**

## 使い方

本文を選択 → サイドバーでモードを選ぶ → 指示を書く → 実行。
出てきた文章は **選択範囲を置換** で本文に直接反映できる。

指示欄は空でもいい。プリセットのチップを押すとよく使う指示が入る。

## 制約

- **応答は一気に出る。** Apps Script は逐次表示（ストリーミング）ができないので、
  実行してから20〜60秒待って、まとめて表示される。
- **長すぎる出力は途中で切れる。** 上限は約8000トークン。切れた場合は範囲を狭めて再実行する。
- **リライトは書式を保持しない。** 置換後のテキストは選択範囲の先頭の書式を継ぐ。
  ルビや文字色を細かく設定している箇所は、置換ではなくコピーして手で貼るほうが安全。
- **複数段落にまたがる置換**は、先頭段落に新しい本文を入れ、残りの段落を削除する。
  意図しない結果になったら Ctrl+Z で戻せる。

## 設定を変える

`Code.gs` 冒頭の定数で調整できる。

- `MAX_TOKENS` — 一度に返せる長さ。長い原稿を書かせたいなら増やす（待ち時間も伸びる）
- `BODY_LIMIT` / `SETTINGS_DOC_LIMIT` — 読み込む文字数の上限
- `ROLE_PROMPT` — 編集者としての振る舞い。文体の好みが決まってきたらここに書き足す
- `MODE_PROMPT` — 各モードの指示文
- モデルを変えたい場合はスクリプトのプロパティ `CLAUDE_MODEL` に別のモデルIDを入れる
