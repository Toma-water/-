# 『灰と炉と、約束の木』設定資料 — 第一章

## 0. テーマ

**縛るか、喰らうか、約束するか。**

人が精霊に対して、人が人に対して、国が国に対して。三つのうちどれを選ぶのか。
第一章はこの問いに対して、主要人物がそれぞれ答えを出す話。

---

## 1. 魔法体系

| 技法 | やること | 使う者 | 象徴 |
|---|---|---|---|
| 契約（けいやく） | 名を交わし、対等な約束を結ぶ | 賢者。王国の正統技術 | 約束する |
| 使役（しえき） | 名を縛り、道具として使い潰す | 軍・教会・奴隷商・帝国 | 縛る |
| 宿し（やどし） | 己の体を器にして精霊を招き入れる | 炉の民のみ。禁忌 | 喰らう |

### 精霊について
可愛い妖精ではなく、現象そのものの人格化。火、風、川、疫、飢え、剣、約束。
名を持ち、痛みを感じ、機嫌がある。

### 「宿し」の出力先
- **肉に宿す** → 筋力・反射・治癒が跳ね上がる。姉ヴェルナの流派。素手で騎兵を殴り落とす。
- **感覚に宿す** → 精霊の知覚をそのまま借りる。精霊が何を考えているかが「視える」。
- つまり炉の民は、この世で唯一、精霊の内側を知っている人間。
- 賢者が何十年もかけて推し量るものを、一族の娘は生まれつき視てしまう。

→ **姉は殴る方に、妹は視る方に振り切った。同じ血。**
→ 主人公が賢者を目指すのは飛躍ではなく、一族の血のもう一つの使い道。

### 解宿の陣（かいしゅくのじん）
オルドが設計した、宿しを強制的に剥がす術式。
これがなければ十年前の虐殺は成立しなかった。彼の手は本当に汚れている。

## 2. 炉の民（ろのたみ）／氏族名アシュヴァル

- 他称・蔑称：**緋喰い（ひぐい）**
- 国境の半遊牧民。どちらの国にも属さなかった。

### 身体的特徴
- **緋色の髪**：燠火のような、光の当たり方で色が動く赤
- **炉印（ろじるし）**：うなじから背骨に沿って走る、生まれつきの熾火色の紋様。
  精霊を宿すと熱を持って光る。鎖骨・前腕にも枝が伸びる
- **金の輪**：虹彩の外周に細い金の環。宿している間だけ濃くなる

### 灰被り（はいかぶり）
主人公の髪偽装術。母から習った、**灰の小精霊を髪に宿す技**。
→ 正体を隠すために、隠している当の禁忌を使っている、という構造。
→ 感情の高ぶり／力の使用／灰の精霊の衰弱で解ける。露見シーンが理屈で起きる。
→ 奴隷時代の呼び名「灰（ハイ）」と連動。

## 3. 国

### リンドヴァルト王国（舞台）
「約束の国」。建国神話は、初代王が大精霊と**対等な契約**を結んだ話。
王権の正統性は血統ではなく**契約**にある。王は精霊と国民双方への「約束の保持者」。

- **王都エルゼン**：中央に《炉》。建国契約の依代。この火が消えると国の契約が切れると信じられている
- **七賢（しちけん）**：七つの大契約を保持する七人。魔法使いの称号ではなく国家の約束の管理職。
  空席が出たときのみ叙任試験。受験には王立エルゼン学院・契約科の卒業が要る。
  入学には身分（自由民以上）が要る。→ 奴隷では不可能 → 終章の誓従の申し出へ繋がる
- **誓従（せいじゅう）**：王族が個人的に選び、誓約環を交わす近侍。命令ではなく約束で従う。
  奴隷の隷属環と形は同じで意味が正反対

> 「近従」の表現候補：
> - **誓従（せいじゅう）** ← 推奨。隷属環↔誓約環の対比が効く
> - 王杖（おうじょう）：公式称号寄り
> - 灯番（ひばん）：古語で親密
> - 影従（えいじゅう）：密偵寄り

### アズガル帝国（隣国）
**使役**の国。精霊を工業的に縛って使い潰す。強い。
リンドヴァルトの「約束」を非効率な迷信と嗤う。

## 4. 十年前の真相（第一章で段階的に開示）

1. 炉の民は国境の半遊牧民。どちらの国にも属さなかった
2. 帝国が**一族の女子供三百人を人質に取り**、リンドヴァルト王暗殺を命じる
3. 断れなかった。姉ヴェルナが実行部隊を率いて王都襲撃
4. **王城でヴェルナは第一王子ラインハルトと鉢合わせる。**夢を誓い合った友と、殺しに来た側で。
   ラインハルトは驚愕する。ヴェルナは何も言わずに背を向けた
5. 王は死んだ。帝国は人質を解放しなかった。**どのみち解放する気がなかった**
6. 報復として村が焼かれる。オルドは解宿の陣の設計者として従軍。彼が斬った相手もいる
7. 生き残った子供は奴隷として散る。シェラもその一人

### ネックレス（姉の遺品）の真相
シェラと姉のペアルック。二つで一つ。
ヴェルナは王都襲撃で大宿しを行い、焼き切れかけていた。
自分を止めてくれと、夢を誓い合った友オルドに頼んだ。
オルドが手を下した。ヴェルナは死に際にネックレスを渡し、「妹を頼む」と言った。
→ オルドは八年間シェラを探し続けた。買ったのは偶然ではない。

## 6. 第一章 構成

### 第一部『灰被り』（1〜6話）
奴隷市で買われる → 不信 → 山賊／暴走精霊の危機 → 師匠と兄弟子に救われる → ほんの少し心を開く
- 仕掛け：師匠は最初から正体を知っている。「その髪はそのままにしておけ」

### 第二部『薔薇の護衛』（7〜14話）
ロゼ護衛任務 → ロゼはライにべったり、シェラを見下す → 道中で不本意に打ち解ける
→ **帝国の使役師が意図的に灰被りを剥がす** → 緋の髪と炉印が露わに
→ ロゼの糾弾「なぜあなたはこの子と一緒にいるの、父を殺されておいて！」
→ ロゼ逃走 → シェラが救出 → 和解 → 別離
- ロゼは「両方とも父親を殺された側」という事実に自分で気づいて壊れる

### 第三部『緋の再会』（15〜21話）
一族の生き残りと接触 → 「帰っておいで」 → **師匠の荷からネックレスが出る**
→ シェラ「わたしを嗤っていたのか」 → 決別 → 一族と共に去る
→ だが一族の怒りの向かう先に、シェラは温かかった人々の顔を見てしまう

### 第四部『約束の木』（22〜28話）
ライが単身追ってきて捕虜になり、ぼこぼこにされている
→ 「なんでそこまでして」「兄だから。家族だから」
→ **過去の家族に囚われた少女が、今の家族と向き合う**
→ オルド登場、真相開示 → ガルが**大宿し**（災いの大精霊を土地ごと器にする）を発動
→ オルドは自分の精霊と契約帳とネックレスをふたりに預け、
  **禁忌の宿しで大精霊を己に招き、自らを閉じる**
→ 跡地に**灰の木**が生える

- 最大の反転：断罪した禁忌を、自分の体で使って世界を止める。誰に習ったかといえば、ヴェルナに。

### 終章（29〜30話）
シェラは賢者を志す。学院に入るには身分が要る。
ライが隷属環を切り、誓約環を差し出す。
「王と賢者。あいつらの約束を、俺たちが果たす」→ 学園編へ

---

## 7. 学園編への引き継ぎ

師匠から託された精霊 **シルヴァ** は、シェラに一言も口をきかない。
オルドを愛していたシルヴァにとって、シェラは「精霊を喰う血」だから。**怖がられている。**

学園編の情緒の芯：
シェラが一族の技（喰らう）を一切使わずに、賢者の技（約束する）だけでシルヴァの信頼を勝ち取ること。
師匠が最後に彼女へ遺した宿題。
